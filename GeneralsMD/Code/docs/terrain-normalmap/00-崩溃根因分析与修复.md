# 地表法线凹凸（P1）— 崩溃根因分析与修复记录

**日期**：2026-08-16
**状态**：崩溃已修复，游戏稳定运行（验证到第 10557 帧）；真法线凹凸可见，正在进行调优（凹凸强度 / 粗糙度 / 山坡平滑）。

---

## 一、问题现象

P1 真法线凹凸（SAGE 原版贴图 + Sobel 生成法线 + 派生 TBN）实现后，进入游戏时**崩溃跳出**：

```
Uncaught Exception in GameEngine::update
code = -559087614  (0xDEAD0002 = ERROR_OUT_OF_MEMORY)
```

崩溃发生时地表已出现变化（法线图集正在生成/绑定），但进程直接抛异常退出，无法游玩。

## 二、排查过程（诊断日志法）

崩溃码 -559087614 = 0xDEAD0002 = ERROR_OUT_OF_MEMORY。SAGE 错误码是抛出的枚举，因此对全引擎所有 `ERROR_OUT_OF_MEMORY` 抛出点逐个插桩，写入 `E:\terrain_diag.log`（fopen/fclose 即时落盘，不需等待 flush）：

| 插桩标记 | 位置 |
|---------|------|
| OOM_DMA_ALIGN | GameMemory.cpp DMA 对齐检查（_INTERNAL 构建） |
| OOM_REALLOC | GameMemory.cpp realloc 重载 |
| **OOM_POOLCREATE** | **GameMemory.cpp 池创建守卫 ← 命中** |
| OOM_SYSALLOC | GameMemory.cpp sysAllocateDoNotZero |
| OOM_POOL | GameMemory.cpp 池扩容 |
| OOM_ASCIISTRING / OOM_ASCIIFORMAT | AsciiString.cpp 分配/格式化 |
| OOM_UNICODESTRING / OOM_UNICODEFORMAT | UnicodeString.cpp 分配/格式化 |
| OOM_DICT | Dict.cpp ensureUnique |

第四份诊断日志命中：

```
[<时间戳>] OOM_POOLCREATE pool=NormalMapTerrainTextureClass init=0 overflow=0
```

→ 这是**本功能自身引入的回归**：新增的 `NormalMapTerrainTextureClass` 内存池没有在注册表登记。

## 三、根因（已确认）

`NormalMapTerrainTextureClass`（`TerrainTex.h` 类声明）用了内存池宏 `W3DMPO_GLUE(NormalMapTerrainTextureClass)`。该宏首次实例化时调用 `createW3DMemPool("NormalMapTerrainTextureClass", sizeof(...))`（`GameMemory.cpp`），内部走 `createMemoryPool(name, size, 0, 0)`，再到 `MemoryInit.cpp` 的注册表（sizes[]）查询预分配数量：

- **表里有条目** → 覆盖 init/overflow 计数 → 正常建池；
- **表里没有条目** → init 保持 0 → 触发守卫抛出 OOM：
  ```cpp
  if (initialAllocationCount <= 0 || overflowAllocationCount < 0)
      throw ERROR_OUT_OF_MEMORY;
  ```

此前 W3X 集成遇到过**完全相同的坑**（`W3XRenderObjClass` 池未注册导致崩溃，见 `docs/w3x-integration/03-根因分析确认.md`），修复手法一致：在注册表补一行。

## 四、修复

`GameEngine/Source/Common/System/MemoryInit.cpp` 注册表，紧跟 `{ "TerrainTextureClass", 4, 4 },` 之后插入：

```cpp
{ "NormalMapTerrainTextureClass", 4, 4 },
```

**关键**：MemoryInit.cpp 属于 **GameEngine** 项目 → 必须 **Rebuild All**（不能只编译 GameEngineDevice）。

## 五、验证（用户确认）

修复后游戏正常运行，地表有可见变化，稳定跑到第 10557 帧。诊断日志确认：基础贴图（s0/s1）、细节（s4）、法线图集（s5）正常绑定，四个 PBR 变体（base / noise1 / noise2 / noise12）全部注册成功。

## 七、崩溃后调优（同主题进行中）

修复后反馈："凹凸不够明显，有些山坡部分看上去突兀"，已做三项优化：

1. **粗糙度参数化**：4 个地形 shader 中写死的 `float roughness = 0.6;` 改为 `float roughness = c2.y;`；C++ 端新增可调常量 `s_terrainRoughness = 0.5f`（越低高光越锐利、凹凸越明显；向 0.7~0.8 走更哑光）。
2. **坡度衰减法线混合**：`N = lerp(geoN, nmN, c2.x * slopeAtten)`，其中
   ```
   float slopeAtten = saturate(1.0 - (1.0 - geoN.y) * 0.75);
   ```
   平地（geoN.y≈1.0）衰减 1.0（法线贴图全效）；陡坡（geoN.y→0.2）衰减约 0.4，贴图法线逐步淡出，避免山坡高光突兀。
3. **Sobel 强度**：`NORMAL_STRENGTH` 6.0 → 8.0，凹凸更明显。
