## 四、分阶段修复计划

### Phase 1：验证剔除修复（环节 F）
- 构建 + 测试 RA3 shader（CullMode 修复 + 蒙皮 + 骨骼 index/2）
- 预期模型可见
- 结果分支：
  - **可见 + 炮塔在顶** → 全部环节 OK
  - **可见 + 炮塔错位** → 蒙皮问题 → Phase 2
  - **仍不可见** → 还有渲染状态/PS 问题

### Phase 2：验证蒙皮骨骼（环节 G）— 对照 shader 约定
shader 约定（head1-newvs.FXH）：
```hlsl
int BoneIndex = floor(i.blendindices.x * 2);       // → 顶点存 index/2
float3x3 m = Quaternion2Matrix(WorldBones[Bone]);  // → WorldBones[b] 是四元数
float4 off = WorldBones[Bone + 1];                  // → WorldBones[b+1] 是 偏移+alpha
WorldP = mul(i.position0, m) + off.xyz;
```
**正确基准**：
1. 顶点 `blendindices = 骨骼索引 / 2`（floor(x*2) 恢复）
2. `WorldBones` 每骨 8 float：`[四元数XYZW][偏移XYZ + alpha]`
3. 根骨应为单位四元数 (0,0,0,1) + 偏移 (0,0,0,1)
4. 炮塔骨应把炮塔网格放到车顶
**验证方法**：dump WorldBones 和顶点骨骼索引，对照上述基准

### Phase 3：验证光照输出（环节 H）
- 确认模型有光照（非黑）+ 纹理可见 + 颜色正确
- 若黑/平 → 查 DirectionalLight/AmbientLightColor 或 PS 内部

### Phase 4：清理 + 回归
- 移除诊断日志
- 确认建筑等常规渲染不受影响
