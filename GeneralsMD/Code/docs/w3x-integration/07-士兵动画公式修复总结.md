# 士兵 W3X 蒙皮 + 动画:公式修复总结

> 2026-08-25。导弹兵(EUTEIROCKETS)动作/姿态/关节全部修复,游戏内实测通过。本文记录两个核心 Bug 的根因、修复、代码清单与验证,供后续 W3X 单位(游骑兵/尖兵/其它士兵)调试参考。

## 一、两个核心 Bug 的根因与修复

### Bug 1:骨骼合成乘法顺序反了 → 公式错、身体歪、开火左手持筒

**症状**:开火时身体倾斜约 45°、左手在后右手在前(应右手握把)、筒在左腋下(应右肩)。

**根因**:RA3 导出通道约定是 `channel = bind⁻¹ × animLocal`(**bind 在左**),运行时正确合成是

```
localQuat = bindLocalQuat × animQuat
```

但代码写的是 `localQuat = animQuat × bindLocalQuat`,实际得到 `bind⁻¹ × animLocal × bind`——把 animLocal 被 bind 做了**相似变换(共轭)**。对 bind 为恒等的骨骼无影响,但士兵髋/脊椎/腿/臂的 bind 全部非恒等 → 旋转被扭曲 → 身体倾斜、开火成左手持筒。

**为什么待机/跑看起来对**:待机、跑是相对对称的姿势,共轭误差小;开火是大幅非对称姿势,暴露了错误。与"待机右手持筒对、开火反了"的现象吻合。

**修复**:交换乘法顺序 → `localQuat = bindLocalQuat × animQuat`。

### Bug 2:软混合 lerp 方向反了 → 肘/膝/髋关节面筋

**症状**:站立时肘关节面筋、开火时髋/膝关节面筋,肘最严重。

**根因**:引擎 `blendWeight = w1/(w0+w1)`(bone1 的权重),但 shader 写的是 `lerp(worldP1, worldP0, bw)` = `P1·(1-bw) + P0·bw`,**bw 实际加权给 P0/bone0 → 方向反了**。对称权重(w0=w1=0.5)无影响;关节处**非对称权重**(肘:上臂 0.8 / 前臂 0.2)就混合反 → 顶点被拉到错误骨骼 → 拉伸面筋。

**为什么肘比膝严重**:肘部骨骼权重差异最大,膝次之。

**修复**:shader 全部改成 `lerp(worldP0, worldP1, bw)`,与 RA3 的 `P0·w0 + P1·w1` 及体积阴影 `lerp(P0,P1,bw)` 一致。

- **步兵**(导弹兵/游骑兵/尖兵)用 `w3x_infantry.fx` → `head1-newvs.FXH` 的 `VS_H_Unified`(软混合 lerp 在此)。
- `head3-vsps.FXH` 的 `VS_H_22skin` 只有 `w3x_rastest.fx`(测试)用,改它对步兵无效。

- 软混合方向必须与体积阴影(`W3DVolumetricShadow.cpp` 的 `wp0 + (wp1-wp0)*bw`)一致。

## 五、历史排查记录(参考)

- frame-0 归一化是错的:对帧0≠bind 的剪辑(如 RUNA 运行动画)会把相对运动放大 → 腿摆到髋高面筋。已移除,改用 RAW 通道直接应用。
- BIDA 待机文件曾被脚本损坏(5 处 `<ChannelScalar>`/`<ChannelQuaternion>` 开标签合并坏),已用 Python 修复,可解析(286 帧)。**勿重跑损坏它的脚本**(flatten/bob/merge 变体)。
- ATKZ 是右手的开火动画;SATEA 是左手(勿用于开火)。开火用 ATKZ。
