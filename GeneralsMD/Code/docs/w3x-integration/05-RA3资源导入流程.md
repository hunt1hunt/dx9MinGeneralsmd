# RA3 资源导入绝命时刻 — 完整工作流

> 2026-08-11：天启坦克（APATAVGATTTANK_SKN）贴图 + PBR 全部验证通过。
> 本文档总结本次修复的根因，并给出「把红警3 资源（模型/贴图/shader）替换进绝命时刻 ini」的可复用流程。

## 一、本次修复总结（模型贴图正确 + PBR 效果）

### 1.1 最终正确的状态

| 部件 | 子网格 | 贴图 | 效果 |
|------|--------|------|------|
| 车体 | SKIN_BODY01 | TavGattTank2 (+_NRM/_SPM) | 橄榄迷彩 + 蓝底白字 |
| 炮塔 | SKIN_UP01/02/03 | TavGattTank2 (+_NRM/_SPM) | 橄榄迷彩 + 蓝底白字 |
| 炮管 | SKIN_UP04 | TavBtMstr2 (+_NRM/_SPM) | 黑金属 |
| 轮子 | SKIN_WHEEL | TunTrack (+_NRM/_SPM) | 轮子侧盘 + 胎面 |
| 履带 | SKIN_TREAD | TunTrack (+_NRM/_SPM) | 履带链 |
| 骨架 | SKIN_SP01 | (无贴图, defaultw3d) | 附加件 |

- 所有贴图通过 PBR 着色器渲染（PBR5-10-objects-ARPBR.FX），法线/高光/粗糙度生效。

### 1.2 两个真正的根因

#### 根因 A：UV 的 V 坐标约定相反（贴图被垂直翻转/错位）

`.w3x` 模型的 UV **V=0 在纹理底部**（TunTrack 布局：底部=履带链、顶部=轮子侧盘+胎面；TavGattTank2 含蓝底白字）。
而 **D3D9 采样 V=0 在纹理顶部**。

- 若不翻转：轮子的负 V（本意采顶部轮子贴图）回绕到**底部履带链** → 轮子贴成履带花纹；
  履带的近 0 V（本意采底部履带链）落在**顶部轮子贴图** → 履带贴成轮子。
- 修复：loader 里 `v = 1.0f - rawV`。

> 经验：`.w3x` 统一是 V=0 在底部约定，**全局翻转**即可（天启坦克验证：车体/炮塔/炮管/轮子/履带全翻转后文字方向、迷彩、履带、轮子全部正确）。

#### 根因 B：贴图分配（哪个网格用哪张图）

RA3 模型每个子网格的 `.w3x` 文件里通过 `<FXShader>` 的 `<Constants>` 声明贴图：

```xml
<FXShader ShaderName="objectssoviet.fx">
  <Constants>
    <Texture Name="DiffuseTexture"><Value>TavGattTank2</Value></Texture>
    <Texture Name="NormalMap"><Value>TavGattTank2_NRM</Value></Texture>
    <Texture Name="SpecMap"><Value>TavGattTank2_SPM</Value></Texture>
    ...
```

- 改贴图分配 = 改游戏根目录 `.w3x` 子网格文件里的 `<Value>`。
- 天启坦克的原始分配（参考资源里核对过）：body/turret=TavGattTank2，barrel=TavBtMstr2，wheel/tread=TunTrack。

### 1.3 相关的工程要点

| 要点 | 说明 |
|------|------|
| **切线 T-B 交换** | RA3 网格存 `binormal=+U, tangent=-V`（着色器 `N += nrm.x*WorldB + nrm.y*WorldT`）。**翻转 V 后要取反 tangent**，否则法线贴图凹凸反了。 |
| **不要误判为深度问题** | 轮子被履带盖住是几何正确（履带确实包在轮子外），不是深度 bug。但 G-Buffer 双渲染修复（W3X 只走 Forward）是独立正确的改进。 |
| **D3DX9 effect 完整性** | SetTechnique 在前、参数绑定、CommitChanges、Begin/BeginPass/End 顺序不能乱，否则贴图/矩阵不生效。 |
| **SPM 通道** | RA3 SPM：红=反射度、绿=金属。配套 _NRM（法线）才能出 PBR 质感。 |

## 二、RA3 资源导入绝命时刻流程

### 第 0 步：准备资源

用 **C&C Asset Extractor** 从红警3（Generals 2 素材）提取：

| 类型 | 后缀 | 数量级 | 放哪 |
|------|------|--------|------|
| 模型 | `.w3x`（容器 + 子网格 + 骨骼） | 每模型 ~10+ 个文件 | 游戏根目录 |
| 贴图 | `.dds`（Diffuse/_NRM/_SPM/_K/_D） | 每模型 ~12 张 | `ART\Textures` |
| 贴图声明 | `.xml` | 每贴图 1 个 | `ART\Textures` |
| 着色器 | `.fx` + `.FXH` | ~15 个 | `Shaders\RA3` |

> 参考目录：`E:\红警3解压后资源文件\其他资源文件\`（模型 + 贴图全套）。
> **目录约定（2026-08-11）：所有 RA3 资源统一放 `ART\W3X\`（模型 + 贴图 + XML），shader 放 `Shaders\RA3\`。不要散放到游戏根目录或混进 Generals 自己的 `ART\Textures`，避免文件管理混乱。** `游戏根目录\` = 用户安装绝命时刻的目录（如 `E:\!!!!!!!QWCSB\!!!!!!!QWCSB\`）。

### 第 1 步：放置文件

1. **模型**：把目标模型的所有 `.w3x` 复制到 `ART\W3X\`：
   ```
   ART\W3X\
   ├── APATAVGATTTANK_SKN.w3x              ← 容器（列子对象 + 骨骼引用）
   ├── APATAVGATTTANK_SKL.w3x              ← 骨骼层级
   ├── APATAVGATTTANK_SKN.SKIN_BODY01.w3x  ← 子网格（顶点/法线/UV/切线/三角形）
   ├── APATAVGATTTANK_SKN.SKIN_UP01.w3x    ← ...
   └── ...（每子网格一个文件）
   ```
2. **贴图 + XML**：把 `.dds` + `.xml` 复制到 `ART\W3X\`：
   ```
   ART\W3X\
   ├── TavGattTank2.dds / .xml            ← 漫射
   ├── TavGattTank2_NRM.dds / .xml        ← 法线
   ├── TavGattTank2_SPM.dds / .xml        ← 高光/粗糙度（SPM）
   └── ...
   ```
3. **着色器**：确保 `Shaders\RA3\` 下有入口 fx（`w3x_soviet.fx`/`w3x_tread.fx`）和 PBR 文件链（`PBR5-10-objects-ARPBR.FX` + `head0-COMMON.FXH` ~ `head3-vsps.FXH`）。

### 第 2 步：理解模型文件结构

| 文件 | 作用 | 关键内容 |
|------|------|----------|
| `_SKN.w3x`（容器） | 列出所有子对象 + 引用骨骼 | `<SubObjects>`、`Hierarchy=` 属性 |
| `_SKL.w3x`（骨骼） | 骨骼层级 + 每骨 quat+offset | 每骨 2×float4（旋转四元数 + 位移） |
| `_SKN.SKIN_XXX.w3x`（子网格） | 一个网格的全部数据 | `<Vertices>` `<Normals>` `<TexCoords>` `<Tangents>` `<Binormals>` `<Triangles>` `<FXShader>` |

- 每个子网格一个文件，`SKIN_XXX` 的名字 = 子对象名。
- `<TexCoords>` 的 `<T X=.. Y=..>`：**Y 就是 V，V=0 在底部**（见 1.2 根因 A）。
- `<Tangents>`/`<Binormals>`：RA3 原生带切线，T-B 交换约定。

### 第 3 步：核对/修改贴图分配

打开每个子网格 `.w3x`，找到 `<FXShader>` 里的 `<Constants>`：

```xml
<Texture Name="DiffuseTexture"><Value>贴图名</Value></Texture>
<Texture Name="NormalMap"><Value>贴图名_NRM</Value></Texture>
<Texture Name="SpecMap"><Value>贴图名_SPM</Value></Texture>
```

- 检查 3 个贴图名在 `ART\Textures` 里都有 `.dds`（含 _NRM、_SPM）。
- 想换材质就改这里的 `<Value>`（例如车体/炮塔换回 TavGattTank2、炮管用 TavBtMstr2）。
- **对照参考资源**（`E:\红警3解压后资源文件\`）可拿到原始分配作为基准。

### 第 4 步：Shader 映射（RA3 着色器 → W3X SAS-free override）

RA3 的 `.fx` 用 SAS 动态数组（`VS_H_Array[...]`），D3DX9 无法解析（X3116）。
所以 W3X 渲染用 **SAS-free 的 override fx**，结构相同但 technique 直接编译 `VS_H_11skin + PS_H_ARPBR`：

| RA3 原始 shader | W3X override | 用途 |
|-----------------|--------------|------|
| `objectssoviet.fx` | `w3x_soviet.fx` | 车辆/常规 PBR |
| `objectsalliedtread.fx` | `w3x_tread.fx` | 履带（带 `SUPPORT_TREAD_SCROLLING` 滚动） |

- override fx 里 `#define REPLACE_DEFAULT_TECHNIQUE` 后 `#include "Shaders/RA3/PBR5-10-objects-ARPBR.FX"`，再手写 technique（ZEnable=1, ZFunc=4, ZWriteEnable=1, CullMode=2）。
- 子网格的 `ShaderName`（如 `objectsalliedtread.fx`）会被引擎映射到 override。
- include 解析到游戏根目录（CWD 相对），所以改 shader 要改 `Shaders\RA3\` 副本。

### 第 5 步：接入 ini

在目标单位的 ini（如 `Data\INI\Object\AmericaVehicle.ini`）用 `W3XModelDraw` 模块：

```ini
Draw = W3XModelDraw ModuleTag_01
    DefaultModelName = APATAVGATTTANK_SKN

    ConditionState = NONE
      Model = APATAVGATTTANK_SKN
    End
    ConditionState = REALLYDAMAGED
      Model = APATAVGATTTANK_SKN
    End
  End
```

- `Model = XXX_SKN` 对应根目录的 `XXX_SKN.w3x` 容器文件。
- 原 Humvee 就是 `W3XModelDraw`（`EUTEVHUMVEE_SKN`），直接把模型名换成目标即可。

### 第 6 步：关键坑清单（Checklist）

- [ ] 模型 + 贴图 + XML 都在 `ART\W3X\`（不在游戏根目录、不混进 `ART\Textures`）
- [ ] 3 张贴图（Diffuse/_NRM/_SPM）都在 `ART\W3X\`
- [ ] **UV V 翻转**：loader 里 `v = 1.0f - rawV`（.w3x V=0 在底部）
- [ ] **翻转 V 时取反 tangent**（T-B 交换约定）
- [ ] 子网格贴图分配正确（对照参考资源）
- [ ] 入口 fx 指向 `Shaders\RA3\`（include 已改）
- [ ] ini 用 `W3XModelDraw` + 正确 `Model` 名
- [ ] 构建 Internal（有 DEBUG_LOGGING）才能看 `DebugLogFileI.txt` 诊断

## 三、排查贴图错误时怎么定位

| 现象 | 可能原因 | 检查 |
|------|----------|------|
| 某部件贴成别的部件纹理 | 子网格贴图分配错 / 共享 shader 泄漏 | `[W3X_DIAG] submesh[..] ownD=...` 日志 |
| 花纹方向反 / 文字倒 | UV V 未翻转 | `[W3X_P5] vert[..] rawV -> stored` 日志 |
| 凹凸反了 | tangent 未随 V 翻转取反 | 视觉对比 |
| 轮子/履带像互换 | V 未翻 → 轮子采到履带链、履带采到轮子贴图 | 见根因 A |
| PBR 没效果（平） | 缺 _NRM / _SPM 贴图 | ART\Textures 文件存在性 |
| 部件黑/白 | 贴图未绑定 / effect 缺参数 | `[W3X_P3]` 参数绑定日志 |
