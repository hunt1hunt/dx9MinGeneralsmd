### 2.2 W3X XML 解析映射

| XML 节点 | 目标字段 |
|---------|---------|
| `<Vertices> <V X= Y= Z=/>` | `m_vertexArray` |
| `<VertexNormals> <N X= Y= Z=/>` | `m_normalArray` |
| `<Tangents> <T X= Y= Z=/>` | `m_tangent` |
| `<Binormals> <B X= Y= Z=/>` | `m_bitangent` |
| `<Texcoords> <T Stage= U= V=/>` | `m_uvArray[Stage]` |
| `<Triangles> <T V0= V1= V2=/>` | `m_faceArray` |
| `<VertexInfluences> <I Bone=.../>` | 骨骼权重数组 |
| `<FXShader ShaderName= TechniqueIndex=>` | 存储引用，供 Phase 3 使用 |
| `<Constants> <Texture/Float/Bool>` | 参数列表，供 Phase 3 使用 |
| `<BoundingBox>` / `<BoundingSphere>` | `m_bounds` |

### 4.3 渲染流程

```cpp
void W3XModelDraw::render() {
    // 1. 获取 effect（缓存）
    ID3DXEffect *effect = W3XEffectManager::Instance()->GetEffect(m_fxFile);
    
    // 2. 绑定引擎全局 uniform
    W3XEffectManager::Instance()->BindEngineConstants(effect);
    
    // 3. 绑定 per-instance Constants（来自 .w3x + INI 覆盖）
    for (auto &c : m_constants) c.Apply(effect);
    
    // 4. 渲染每个子网格
    for (auto &mesh : m_subMeshes) {
        effect->SetTechnique(mesh.technique);
        UINT passes;
        effect->Begin(&passes, 0);
        for (UINT p = 0; p < passes; p++) {
            effect->BeginPass(p);
            // 顶点缓冲区 / 索引缓冲区由 effect 内部 setup
            DrawIndexedPrimitive(mesh.vb, mesh.ib, mesh.triCount);
            effect->EndPass();
        }
        effect->End();
    }
}
```

### 4.4 HLod 处理

W3X 的 `<W3DContainer>` 包含多个 `<SubObject>`，每个子对象指向不同的子网格。这对应 Generals 的 HLod 体系：

```
W3DContainer
├── SubObject "SKIN_BODY01" → APATAVGATTTANK_SKN.SKIN_BODY01.w3x
├── SubObject "SKIN_UP01"   → APATAVGATTTANK_SKN.SKIN_UP01.w3x
├── SubObject "SKIN_TREAD"  → APATAVGATTTANK_SKN.SKIN_TREAD.w3x
└── SubObject "SKIN_WHEEL"  → APATAVGATTTANK_SKN.SKIN_WHEEL.w3x
```

每个 SubObject 有自己的 FXShader，需要独立创建 effect 实例或共享。
