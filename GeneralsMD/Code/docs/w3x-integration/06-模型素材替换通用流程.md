# RA3 模型/素材替换绝命时刻 —— 通用流程

> 2026-08-24 总结。在 QWCSB MOD 上验证完整：中方(AP)/GLA(GL)/美方(EU) 载具 + 飞机共 25+ 单位。
> 配套工具：`Tools\ra3_asset_replace.py`（拆分导入/INI改写/校验 三合一）。

---

## 一、概念

红警3(RA3) 的模型是 **W3X** 格式，绝命时刻的 W3X 渲染管线（`W3XModelDraw` + `w3x_loader`）能直接加载，
但要求特定文件布局。替换 = 把 RA3 模型整理成游戏认识的布局 + 把单位 INI 的 W3D Draw 换成 W3XModelDraw。

### W3X 文件布局（游戏 `ART\W3X\` 下）

| 文件 | 内容 | 说明 |
|------|------|------|
| `<MODEL>_SKN.w3x` | **W3DContainer**（列子对象 + `Hierarchy=<MODEL>_SKL`） | 必须；源文件是自包含内联网格，需**拆分** |
| `<MODEL>_SKN.<SUBID>.w3x` | 每个子网格一个 `<W3DMesh>` 文件 | 拆分产物 |
| `<MODEL>_SKL.w3x` | `<W3DHierarchy>` 骨骼层级 | 原样拷 |
| `<MODEL>_<ANIM>.w3x` | `<W3DAnimation>`（IDLA=闲置/ATKA=攻击/…） | 原样拷 |
| 贴图 `.dds` + `.xml` | `_NRM` 法线、`_SPM` 高光/粗糙度、`_D`、`_K` | 贴图统一放 `ART\W3X` |

### INI 里怎么接

```ini
Draw = W3XModelDraw ModuleTag_01
  DefaultModelName = <MODEL>_SKN
  ConditionState = NONE
    Model = <MODEL>_SKN
    Turret = bone_turret          ; 炮塔偏航骨(可省)
    TurretPitch = bone_turretel   ; 俯仰骨(可省)
    WeaponFireFXBone = PRIMARY bone_weapona01
    WeaponLaunchBone = PRIMARY bone_weapona01
    Animation = <MODEL>_IDLA      ; 闲置动画(可省,无动画则静态)
    AnimationMode = LOOP
  End
  ConditionState = REALLYDAMAGED
    ...同上...
  End
End
```

骨骼名大小写皆可（解析器统一转小写）。常用骨：`bone_turret`/`bone_turretel`/`bone_weapona01`/`bone_barrel01`。

## 二、资源位置与命名约定

源目录 `D:\遗忘发来的红警3将军2里的资源\ART\`：

| 子目录 | 内容 | 命名 |
|--------|------|------|
| `AP` | 中方(苏式) 载具/飞机/建筑 | `APATav*`(载具) `APATaa*`(飞机) `APATai*`(步兵) |
| `GL` | GLA 载具/建筑 | `GLATgv*`(载具) `GLATga*/b*`(摩托/火箭车) |
| `EU` | 盟军(美方) 载具/飞机 | `EUTev*`(载具) `EUTea*`(飞机) |
| `TA/TE/TG` | 贴图 | `Tav*`(中) `Tev*`(盟) `Tgv*`(GLA) |
| `TU` | 通用贴图 | `TunTrack`(履带) |
| `FX` | 特效贴图 | `Fx_blades_G2`(桨叶) `FXLaser03` |

模型文件后缀：`_SKL`=骨骼、`_SKN`=皮肤(自包含)、`_IDLA`=闲置动画、`_ATKA`=攻击、`_UPK`=展开、`_PREA`=预备、`_COL`=碰撞。

## 三、四步流程

### 1. 清单（inventory）
读目标 INI（`Data\INI\Object\*.ini`），用脚本列出每个 `Object` 及当前 `Draw` 模块/模型名，确定要换的单位。

### 2. 找模型（map）
按命名约定在源目录找对应模型（如 `ChinaTankBattleMaster`→`APATavBtMstrTech1`）。没有对应模型的单位**保留原模型**。

### 3. 导入（import）
```bash
python Tools\ra3_asset_replace.py import ^
  --src "D:\...\ART" --game "E:\!!!!!!!QWCSB" ^
  --model-sub AP --models "APATavBtMstrTech1,APATavOvrlrd" ^
  --tex-sub TA --tex "TavBtMstr2,TavOvrlrd2"
```
自动完成：拆分 SKN→container+子网格、拷 SKL/动画/贴图。

### 4. 改写 INI + 校验
```bash
python Tools\ra3_asset_replace.py convert ^
  --ini "E:\!!!!!!!QWCSB\Data\INI\Object\ChinaVehicle.ini" ^
  --game "E:\!!!!!!!QWCSB" ^
  --map "ChinaTankBattleMaster=APATAVBTMSTRTECH1,ChinaTankOverlord=APATAVOVRLRD"
# 自动识别骨骼(Turret/TurretPitch/PRIMARY/SECONDARY) + 自动用 *_IDLA

python Tools\ra3_asset_replace.py validate ^
  --game "E:\!!!!!!!QWCSB" --models "APATAVBTMSTRTECH1,APATAVOVRLRD"
```

**强制指定骨骼**（自动识别不理想时）：
```bash
--force "ChinaTankOverlord:secondary=bone_weapong01"
```

**隐藏某子网格**（如不透明旋翼）：
```bash
--hide "SKIN_SCREW01,SKIN_SCREW02"   # import 时传入
```

## 四、坑与注意

- **源 SKN 自包含**：必须拆成 container+子网格，游戏 loader 只认 `<W3DContainer>` + 独立 `<W3DMesh>` 文件。
- **INI Draw 行格式**：源文件可能 `W3DOverlordAircraftDraw  双空格 ModuleTag_01;注释` —— 脚本正则已兼容（双空格/注释），改写时限定在对象体内搜索，避免误改到后面的对象（曾误改盘旋的升级件）。
- **骨骼拼写**：`EUTevCrusader` 的俯仰骨是 `bone_turrtel`(少个 E)；工具已兼容 `bone_turrtel` 变体。
- **飞机静态限制**：RA3 飞机模型 IDLA 动画空通道、无旋翼骨 → 旋翼不转、无尾焰。旋翼子网格(`SKIN_SCREW*` 用 `Fx_blades_G2` 透明桨叶贴图)在 W3X 下透明失效变不透明四边形 → 用 `--hide` 隐藏。
- **升级件/依赖挂接**：`W3DDependencyModelDraw` 引用 `FIREPOINT01` 骨，新模型若无此骨则视觉不挂接（武器仍工作）。
- **缺贴图会黑但不崩**：导入后跑 `validate` 能查漏。
- **release 构建关 W3X 日志**：排查加载问题要用 Internal 构建(`RTSI*.exe`)复现，看 `DebugLogFileI.txt` 的 `[W3X_P2]/[W3X_P5]`。
