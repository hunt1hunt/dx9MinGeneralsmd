## 对照分析建议（与 SagePerfDiag 衔接）

1. **基线选取**：DX9 迁移（47d9db16）、延迟渲染完成（03f45818）、贴图阴影贯通（7d610544）三个提交是天然 A/B 基准点——各代表一次渲染架构级变更，用 SagePerfDiag 在同地图同回放下测 `t_render`/`shadow_pass_ms` 增量，即可量化每次升级的性能代价。
2. **回归排查**：水面倒影（逐水域独立反射）与贴图阴影（相机跟随窗口重绘）是当前最可能的帧时间大户；旋翼/TSS 系列（09-03~04）证明 shader 状态流改动极易跨子系统回归。
3. **风险区标注**：阶段 5/6 仍在活跃开发（W3XRenderObj.cpp 当前有未提交改动），诊断插桩避开该文件热区或与开发者协调。
